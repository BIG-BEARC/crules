#### 三、修法审查（对需求方四点方案——两处有漏）

| 方案 | 缺口 |
|---|---|
| ① 剥离名单加 `env\|sudo\|nohup\|nice\|time` | 前缀**带参数**仍穿：`sudo -u root git reset --hard`（剥 `sudo` 后剩 `-u root git…`，锚定又失效）、`nice -n 5 git …` 同理。枚举前缀词=打地鼠 |
